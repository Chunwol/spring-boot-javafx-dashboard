## 1. 시작하기

### 1.1 시스템 요구사항
- **운영체제**: Windows 10/11, macOS, Linux
- **Java**: 17 이상
- **네트워크**: 서버(포트 8888 또는 443)에 접근 가능

### 1.2 프론트엔드 실행
```bash
# Windows
.\gradlew.bat :frontend:run

# Linux/Mac
./gradlew :frontend:run

# 또는 플랫폼별 JAR 직접 실행
java -jar dist/frontend/frontend-win.jar
java -jar dist/frontend/frontend-mac.jar
java -jar dist/frontend/frontend-mac-aarch64.jar
java -jar dist/frontend/frontend-linux.jar
```

## 2. 로그인

### 2.1 로그인 화면

프론트엔드를 실행하면 로그인 화면이 표시됩니다.

| 입력란 | 설명 | 예시 |
|--------|------|------|
| **도메인 또는 IP** | 백엔드 서버 주소 | `pelmon.kro.kr` 또는 `192.168.1.100` |
| **포트** | 서버 포트 번호 (1~65535) | `443` (HTTPS) 또는 `8888` (로컬) |
| **사용자명** | 관리자 계정 ID | `admin` |
| **비밀번호** | 관리자 비밀번호 | - |

### 2.2 로그인 방법
1. 서버 주소와 포트를 입력합니다.
2. 사용자명과 비밀번호를 입력합니다.
3. **로그인** 버튼을 클릭하거나 **Enter** 키를 누릅니다.
4. 인증 성공 시 대시보드 화면으로 전환됩니다.

> **참고**: 마지막으로 접속한 서버 주소와 포트는 자동 저장되어 다음 로그인 시 자동으로 채워집니다.

### 2.3 로그인 실패 시
- 빨간색 메시지가 표시됩니다.
- 서버 주소/포트가 올바른지 확인하세요.
- 네트워크 연결을 확인하세요.

## 3. 대시보드 둘러보기

### 3.1 화면 구성

로그인 후 대시보드는 다음과 같은 구조입니다:

```
┌─────────────────────────────────────────────────┐
│ [상단바]                                         │
│ 타이틀 | 대시보드선택 | +대시보드 | 상태요약 | 시계 | 로그아웃 │
├────┬────────────────────────────────────────────┤
│    │ [탭1] 메인 | [탭2] 네트워크 | [탭3] 명령 | [탭4] 관리 | [탭5] PC관리 │
│ 리 ├────────────────────────────────────────────┤
│ 소 │                                            │
│ 스 │         메인 캔버스 영역                      │
│ 패 │     (강의실 패널, 위젯 자유 배치)              │
│ 널 │                                            │
│    │                                            │
├────┴────────────────────────────────────────────┤
│ [하단바] 편집모드 | 포커스모드 | 줌 | 배경색 | 정렬  │
└─────────────────────────────────────────────────┘
```

### 3.2 상단바 요소

| 요소 | 설명 |
|------|------|
| **대시보드 선택기** | 여러 대시보드를 만들어 전환할 수 있습니다 |
| **+ 대시보드** | 새 대시보드를 생성합니다 |
| **상태 요약** | "강의실 5, 온라인 42/60" 형태로 전체 현황 표시 |
| **연결 상태** | WebSocket 연결 상태 (정상/끊김) |
| **시계** | 현재 시간 실시간 표시 |
| **로그아웃** | 로그아웃하고 로그인 화면으로 돌아갑니다 |

### 3.3 탭 소개

| 탭 | 용도 |
|----|------|
| **탭 1: 메인 대시보드** | 강의실 패널, 위젯을 자유 배치한 메인 모니터링 화면 |
| **탭 2: 네트워크 트래픽** | 실시간 인바운드/아웃바운드 트래픽 모니터링 |
| **탭 3: 명령 상태** | 발행된 명령의 진행 상태 추적 |
| **탭 4: 관리** | 에이전트·IP 대역·교사장치·고장PC·보고서 관리 |
| **탭 5: PC 관리** | PC 목록 조회 및 원격 명령 전송 |

## 4. 강의실 패널 사용법

### 4.1 강의실 패널 구성

각 강의실 패널에는 다음 정보가 표시됩니다:

| 영역 | 표시 내용 |
|------|----------|
| **강의실명** | 강의실 이름 (예: "실습실 101") |
| **온라인/전체 PC** | 현재 접속 중인 PC 수 / 전체 등록 PC 수 |
| **교사 PC 상태** | ONLINE 또는 OFFLINE |
| **IP 대역** | 할당된 IP 대역 (예: 192.168.10.0/24) |

### 4.2 강의실 패널 액션

| 버튼 | 동작 |
|------|------|
| **전체 종료** | 해당 강의실의 모든 온라인 PC에 종료 명령을 전송합니다 |
| **전체 켜기 (WOL)** | 해당 강의실의 오프라인 PC를 WOL로 켭니다 |

> **WOL 작동 조건**: 강의실 내에 최소 1대 이상의 PC가 온라인이어야 합니다. 온라인 에이전트가 매직패킷을 릴레이합니다.

### 4.3 리소스 패널에서 추가하기

좌측 리소스 패널에서 항목을 클릭하면 캔버스에 추가됩니다:
- **강의실 패널**: 등록된 강의실 패널을 대시보드에 배치
- **텍스트 위젯**: 메모용 텍스트 영역 추가
- **이미지 위젯**: 이미지 파일 업로드 후 표시
- **네트워크 패널**: 전체 네트워크 트래픽 요약 패널
- **접속끊김 패널**: 접속이 끊긴 PC 현황 패널

## 5. 대시보드 꾸미기 (편집 모드)

### 5.1 편집 모드 진입
- 하단바의 **편집 모드** 버튼을 클릭합니다.
- 활성화되면 패널의 테두리에 이동/리사이즈 핸들이 표시됩니다.

### 5.2 패널 이동
- 편집 모드에서 패널 상단을 드래그하여 원하는 위치에 놓습니다.
- 위치 변경은 자동으로 서버에 저장됩니다.

### 5.3 패널 크기 조절
- 패널 우측 하단의 리사이즈 핸들(◢)을 드래그합니다.

### 5.4 정렬·배열
- **정렬**: 여러 패널 선택 후 좌/우/상/하 정렬
- **배열**: 패널을 격자/가로/세로로 자동 배열

### 5.5 보기 모드

| 모드 | 설명 | 단축키/버튼 |
|------|------|-----------|
| **편집 모드** | 패널 이동/리사이즈 활성화 | 하단바 토글 |
| **포커스 모드** | 좌측 패널 숨기고 캔버스 최대화 | 하단바 토글 |
| **대시보드만** | 상단바+좌측 패널 모두 숨김 | 하단바 토글 |
| **전체 화면** | OS 풀스크린 | 하단바 토글 |

### 5.6 줌 컨트롤
- **확대(+)**: 캔버스를 확대합니다
- **축소(-)**: 캔버스를 축소합니다
- **100%**: 원래 크기로 복원합니다
- **전체 맞춤**: 모든 패널이 보이도록 자동 줌 조절

### 5.7 배경색 변경
- 하단바의 ColorPicker로 캔버스 배경색을 변경할 수 있습니다.

### 5.8 다중 대시보드
- **+ 대시보드** 버튼으로 새 대시보드를 만들 수 있습니다.
- 상단바의 ComboBox로 대시보드를 전환합니다.
- 각 대시보드는 독립적인 패널 구성을 가집니다.

## 7. 명령 상태 확인

### 7.1 [탭 3] 명령 상태 화면

발행된 모든 명령의 상태를 실시간으로 추적합니다.

| 요약 영역 | 표시 |
|----------|------|
| **진행중** | QUEUED(Q) + DELIVERED(D) + ACKED(A) 합계 |
| **완료** | COMPLETED 건수 |
| **실패** | FAILED 건수 |

### 7.2 명령 상태 의미

| 상태 | 의미 | 색상 |
|------|------|------|
| **QUEUED** | 서버에 대기 중, 아직 에이전트 미전달 | 회색 |
| **DELIVERED** | 에이전트에 전달됨, ACK 대기 중 | 파란색 |
| **ACKED** | 에이전트가 수신 확인, 실행 중 | 노란색 |
| **COMPLETED** | 실행 완료 (exitCode = 0) | 초록색 |
| **FAILED** | 실행 실패 | 빨간색 |

> 10초 간격으로 자동 갱신됩니다.

## 8. PC 관리 및 원격 제어

### 8.1 [탭 5] PC 관리 화면

#### 필터링
| 필터 | 설명 |
|------|------|
| **전체 PC** | 등록된 모든 PC 표시 |
| **강의실별** | 특정 강의실에 배정된 PC만 |
| **교사 PC만** | 교사 역할의 PC만 |

#### PC 테이블 정보
| 컬럼 | 내용 |
|------|------|
| 강의실 | 소속 강의실명 |
| IP 주소 | PC의 IP 주소 |
| 호스트명 | PC 이름 |
| 역할 | 교사 / 학생 |
| 상태 | 온라인 / 오프라인 |
| 마지막 접속 | 마지막 하트비트 시간 |

### 8.2 원격 명령 전송

#### 1단계: 대상 선택
테이블에서 PC를 클릭하여 선택합니다. **Ctrl+클릭**으로 여러 PC를 선택할 수 있습니다.

#### 2단계: 명령 대상 지정
| 옵션 | 설명 |
|------|------|
| **전체 PC** | 등록된 모든 PC에 전송 |
| **선택 강의실** | 해당 강의실 모든 PC |
| **교사 PC만** | 교사 역할 PC만 |
| **선택 PC** | 테이블에서 선택한 PC만 |

#### 3단계: 명령 종류 선택
| 명령 | 동작 |
|------|------|
| **PC 켜기 (WOL)** | 오프라인 PC를 Wake-on-LAN으로 켭니다 |
| **재시작** | 선택 PC를 원격 재시작합니다 (10초 후) |
| **종료** | 선택 PC를 원격 종료합니다 (10초 후) |
| **스크립트 실행** | 업로드된 PS1 스크립트를 실행합니다 |

#### 4단계: 전송 확인
- 확인 다이얼로그가 표시됩니다.
- 오프라인 PC에는 명령이 전송되지 않습니다 (WOL 제외).

## 10. 자주 묻는 질문 (FAQ)

### Q: 강의실 패널에 PC가 표시되지 않습니다.
**A:** 다음을 확인하세요:
1. 해당 강의실에 IP 대역이 등록되어 있는지 확인 (탭 4 → IP 대역 관리)
2. PC에 에이전트가 설치·실행 중인지 확인
3. 에이전트가 올바른 서버로 하트비트를 전송하는지 확인

### Q: WOL(전체 켜기)이 동작하지 않습니다.
**A:** WOL은 다음 조건이 필요합니다:
1. 대상 PC의 BIOS에서 Wake-on-LAN이 활성화되어 있어야 합니다
2. 해당 강의실에 최소 1대 이상의 PC가 **온라인**이어야 합니다 (릴레이 역할)
3. 네트워크 스위치가 매직패킷을 차단하지 않아야 합니다

### Q: 명령을 보냈는데 "QUEUED" 상태에서 변하지 않습니다.
**A:** 명령은 에이전트의 다음 하트비트 때 전달됩니다. 하트비트 간격은 약 120초(±30초)입니다. 잠시 기다려 주세요. 180초 이후에도 변하지 않으면 해당 PC가 오프라인인지 확인하세요.

### Q: 대시보드에서 WebSocket 연결이 끊겼다고 표시됩니다.
**A:** WebSocket이 끊기더라도 15초 주기 HTTP 폴링으로 데이터가 갱신됩니다. 다만 실시간성이 약간 떨어질 수 있습니다. 서버 연결 상태를 확인하세요.

### Q: 여러 대시보드를 만들 수 있나요?
**A:** 네, 상단바의 **+ 대시보드** 버튼으로 여러 대시보드를 만들 수 있습니다. 각 대시보드는 독립적으로 패널을 구성할 수 있어, 용도별(모니터링용, 프레젠테이션용 등)로 구분하여 사용하면 편리합니다.

### Q: 에이전트가 "등록 실패"로 종료됩니다.
**A:** 다음을 확인하세요:
1. `config.json`의 `serverUrl`이 올바른지 확인
2. `installKey`가 서버에 설정된 값과 일치하는지 확인 (관리 탭에서 설치키 조회)
3. 서버에 네트워크 접근이 가능한지 확인 (방화벽 등)

### Q: 스크립트 실행 결과가 "FAILED"로 표시됩니다.
**A:** 가능한 원인:
1. 스크립트에 PowerShell 문법 오류가 있음
2. SHA-256 무결성 검증 실패 (파일 손상) → 스크립트를 다시 업로드해 보세요
3. 스크립트 실행 시간이 5분을 초과함 (타임아웃)
