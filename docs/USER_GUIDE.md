# Web Dashboard User Guide

브라우저에서 운영 서버 주소를 열고 로그인합니다. `아이디 기억`은 아이디만 로컬 저장소에 저장하고, `자동 로그인`은 비밀번호 대신 HttpOnly 갱신 쿠키를 사용합니다. 공용 PC에서는 자동 로그인을 선택하지 마십시오.

주요 화면은 강의실, PC, 명령 이력, 장애 PC, 네트워크, 보고서, 파일 배포, 설정입니다. 역할에 따라 메뉴와 실행 가능한 명령이 달라집니다.

- `VIEWER`: 조회 전용
- `USER`: 허용된 운영 변경
- `ADMIN`: 전원·스크립트·배포·원격제어·사용자 설정

종료, 재부팅, WOL, 스크립트 실행처럼 PC 상태를 바꾸는 작업은 대상 강의실과 PC 목록을 확인한 뒤 실행합니다. 명령 이력에서 진행 상태를 확인하고, 대기 중인 명령은 취소할 수 있습니다.

로그아웃하면 현재 접근 토큰과 자동 로그인 쿠키가 삭제됩니다.
