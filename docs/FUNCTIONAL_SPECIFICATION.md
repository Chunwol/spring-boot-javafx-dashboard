# 기능명세서 (Functional Specification)

> **문서 버전**: 1.0  
> **최종 갱신일**: 2026-03-30  
> **시스템명**: 통합 강의실 PC 관제·원격제어 시스템

---

## 1. 시스템 개요

### 1.1 목적
학교·기업 강의실 내 다수 PC를 중앙에서 실시간 모니터링하고, 원격으로 제어(종료/재부팅/명령 실행/WOL)할 수 있는 통합 관제 시스템.

### 1.2 대상 사용자
| 역할 | 설명 |
|------|------|
| **관리자** | 시스템 전체 설정, 에이전트 관리, 보고서 생성, 전체 원격 제어 |
| **교사** | 자기 강의실 PC 모니터링 및 원격 제어 (향후 RBAC 예정) |

### 1.3 시스템 구성
| 구성요소 | 기술 스택 | 역할 |
|----------|-----------|------|
| **백엔드 서버** | Spring Boot 3.x, SQLite, JWT, WebSocket/STOMP | REST API, 데이터 처리, 인증, 실시간 통신 |
| **프론트엔드** | React 19, TypeScript, Vite | 브라우저 기반 강의실 관제 UI |
| **에이전트** | Java 25, OSHI, OkHttp | 각 PC에 설치, 하트비트 전송, 명령 실행 |
| **공통 모듈** | Java 25 | 프론트/백엔드 공유 DTO |

## 3. 비기능 요구사항

### 3.1 성능
| 항목 | 기준 |
|------|------|
| API 응답 시간 | 일반 API < 200ms, 대시보드 refresh < 500ms |
| 하트비트 처리량 | 최대 830대 PC 동시 하트비트 처리 |
| 캐시 | IP 대역 해석 Caffeine 캐시 (최대 10,000건, 10분 만료) |
| DB 최적화 | 하트비트 persist 30초 간격, 감사로그 배치 flush |

### 3.2 보안
| 항목 | 방식 |
|------|------|
| 인증 | JWT (HS256, 24시간 만료) |
| 비밀번호 | BCrypt 해시 |
| 에이전트 인증 | X-Agent-Token (SHA-256 해시 저장) |
| 설치키 검증 | 타이밍 어택 방어 (MessageDigest.isEqual) |
| 파일 보안 | Path Traversal 방어, 20MB 제한 |
| 세션 | Stateless (SessionCreationPolicy.STATELESS) |

### 3.3 가용성
| 항목 | 방식 |
|------|------|
| 메일 장애 격리 | NoOp fallback, 예외 처리 |
| 에이전트 자동 복구 | 토큰 거부 시 재등록, 최대 3회 재시도 |
| 명령 재시도 | 180초 타임아웃 후 자동 재큐잉 (최대 3회) |
| 감사 로그 보장 | 셧다운 시 잔여 큐 강제 flush |

### 3.4 호환성
| 항목 | 지원 |
|------|------|
| OS | Windows 10/11 (에이전트), 크로스플랫폼 (프론트/백엔드) |
| Java | 17+ |
| 하트비트 형식 | inboundKbps/outboundKbps (신규) + inboundMbps/outboundMbps (구버전 호환) + traffic 리스트 |

## 5. 외부 인터페이스

### 5.1 에이전트 ↔ 서버
| 인터페이스 | 프로토콜 | 설명 |
|-----------|----------|------|
| 하트비트 | HTTP POST | 120초 주기 (±30초 지터), X-Agent-Token 인증 |
